설정 & 사용법

각 칸에 영문자 또는 숫자 한 글자를 입력하세요.

Ctrl / ⌘ + Z 실행 취소
Ctrl / ⌘ + Shift + Z 다시 실행
Ctrl + Y 다시 실행
Ctrl / ⌘ + S PNG 저장
[ ] 브러시 크기 조절

팔레트 좌클릭은 왼쪽 색, 우클릭은 오른쪽 색을 고릅니다. 터치에서는 먼저 ‘왼쪽’ 또는 ‘오른쪽’ 색 칸을 누르세요. ‘색 교환’으로 터치에 사용할 색도 바꿀 수 있습니다.

이미지 불러오기는 새 레이어를 만듭니다. 빈 곳과 투명한 부분에는 아래 레이어가 보이며, 불러오기도 실행 취소할 수 있습니다. 이미지는 서버로 전송되지 않습니다.

지우개는 선택 레이어를 투명하게 지우고, 비우기는 선택 레이어만 지웁니다. 채우기도 선택 레이어의 경계를 따릅니다. 숨긴 레이어는 표시한 뒤 그릴 수 있습니다. PNG는 보이는 레이어를 흰 배경 위에 합쳐 저장합니다. 최근 30개 작업을 되돌릴 수 있습니다. 비우기도 복구됩니다. PNG에는 레이어 편집 정보가 포함되지 않습니다. 그림은 자동 저장되지 않으니 창을 닫기 전에 PNG로 저장하세요. 필압을 지원하지 않는 기기에서는 일정한 굵기로 그려집니다.
