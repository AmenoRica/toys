설정 & 사용법

각 칸에 영문자 또는 숫자 한 글자를 입력하세요.

Ctrl / ⌘ + Z 실행 취소
Ctrl / ⌘ + Shift + Z 다시 실행
Ctrl + Y 다시 실행
Ctrl / ⌘ + S PNG 저장
[ ] 브러시 크기 조절

팔레트 좌클릭은 왼쪽 색, 우클릭은 오른쪽 색을 고릅니다. 터치에서는 먼저 ‘왼쪽’ 또는 ‘오른쪽’ 색 칸을 누르세요. ‘색 교환’으로 터치에 사용할 색도 바꿀 수 있습니다.

최근 30개 작업을 되돌릴 수 있습니다. 비우기도 복구됩니다. 그림은 자동 저장되지 않으니 창을 닫기 전에 PNG로 저장하세요. 필압을 지원하지 않는 기기에서는 일정한 굵기로 그려집니다.
