잉크

HTML 캔버스를 지원하는 브라우저가 필요합니다.

사용법

흰 영역을 클릭하거나 터치하면 잉크가 날아와 찍힙니다. 방울은 아래로 흘러내려 자국을 남깁니다.

‘배경 이미지’로 바탕을 고르고, ‘잉크 이미지’로 잉크 안에 드러날 이미지를 고릅니다. 두 이미지는 각각 작업 영역을 꽉 채우고 중앙에 정렬되며 가장자리가 잘릴 수 있습니다.

‘비우기’는 이미지를 유지한 채 잉크만 지웁니다. 이미지 버튼을 다시 누르면 다른 이미지로 바꿀 수 있습니다.

캔버스에 Tab으로 초점을 둔 뒤 Enter 또는 스페이스를 누르면 가운데에 발사합니다. 동작 줄이기 설정에서는 최종 자국을 바로 표시합니다.

이미지는 기기 안에서만 읽으며 업로드하지 않습니다. 이미지와 잉크는 저장되지 않아 새로고침하거나 페이지를 나가면 사라집니다.
