변환 WAV 다운로드
사용법 · 지원 형식

파일이나 마이크 녹음에 오징어·문어풍 음성 효과를 적용합니다. 오디오는 브라우저 안에서 처리합니다.
파일은 프리셋을 선택하고 변환하세요. 녹음은 종료 후 자동 변환합니다. 재생 버튼을 눌러 들어보세요.
원본 녹음과 변환 결과는 WAV로 저장할 수 있습니다.

입력: WAV · MP3 · M4A/AAC · FLAC · OGG. 추가 형식의 코덱 지원은 브라우저에 따라 다릅니다.
모노 또는 스테레오 · 최대 64MiB / 1,200만 샘플.
WAV는 44.1~192kHz를 지원하며 원본 샘플레이트를 유지합니다. 추가 형식은 48kHz로 처리하며 최대 250초입니다.
스테레오는 좌우 평균으로 모노 처리합니다. 출력은 32비트 float 모노 WAV입니다.
녹음은 48kHz 모노이며 최대 250초에 자동 종료합니다. HTTPS 또는 localhost와 마이크 권한이 필요합니다.
끝소리 보존을 위해 0.5초를 더 처리합니다. 프리셋의 LFO 속도는 고정입니다.
