# 문자 줄이기 — 배포 준비 기록

정적 실행 파일은 `docs/unicode-squeeze/`, 목록 항목은 `docs/index.html`입니다. `/toys/unicode-squeeze/` 하위 경로를 유지하도록 링크, JSON, worker, 폰트를 모두 상대 경로로 불러옵니다. 빌드나 서버 측 처리는 없으며 입력 문자열을 외부에 전송하지 않습니다.

## 동작

- 기본: Unicode 정규화와 Security confusables에서 추출한 공식 규칙 527쌍.
- 카오스 모드: 기본 해제. 켜면 검토용 시각 후보 183쌍을 더한 710쌍을 사용합니다. 끄면 즉시 공식 규칙으로 재계산합니다.
- 항상 최소 코드포인트 길이를 먼저 선택합니다. 동률이면 정규화 → confusables → 시각 후보, 이후 코드포인트 오름차순입니다.
- 랜덤 셔플은 출처와 무관하게 최소 길이를 만드는 선택지 사이에서 동작합니다. 전체 문자열 결과에 대한 균등분포를 보장하지는 않습니다.
- 대소문자 무시는 ASCII 영문에만 적용합니다. 변환은 원문에 한 번만 적용하며 결과를 재귀적으로 치환하지 않습니다.
- 원문과 결과의 바뀐 구간 색 표시, 긴 입력의 worker 처리, RTL 치환 제외를 유지합니다.

## 출처와 배포 범위

`rules.json`은 공식 규칙과 근거를, `visual-rules.json`은 시각 후보·측정 기준·원본 아티팩트 해시를 기록합니다. 공식 데이터 URL/해시는 `licenses/unicode-sources.json`, Unicode 라이선스는 같은 폴더에 있습니다. 동봉 25개 폰트와 각 라이선스/출처는 `fonts/manifest.json`에 있습니다. 폰트는 외부 서버에서 요청하지 않습니다.

카오스 후보는 143,312개 영문 2–3글자 조합 × 렌더링 가능한 대상 74,236개를 최신 기준으로 재검색한 결과입니다. 이전 후보 598쌍에서 제외된 415쌍은 포함하지 않습니다. 24px 형태 검사 결과일 뿐 신뢰도나 가독성 점수는 부여하지 않습니다. 짧은 획 변화 등의 오탐은 남을 수 있습니다.

## 확인한 항목

```sh
node tests/unicode-squeeze/compressor.test.mjs
node tests/unicode-squeeze/chaos.test.mjs
git diff --check
python3 -m http.server 8875 --bind 127.0.0.1 --directory docs
```

- 기존 회귀 검사와 두 모드의 최소 길이·대소문자·랜덤 경로 검사: 총 1,240회 완전탐색 대조.
- 183개 시각 후보, 공식 우선순위, 모드 분리, 하이라이트 인덱스, RTL 제외.
- 공식+시각 후보 출력 582종 모두 동봉 폰트 cmap에 존재함을 확인.
- 브라우저에서 실제 worker 변환, 모드 켜기/끄기, 셔플, 원문/결과 하이라이트를 확인.
- 데스크톱 및 390px 폭에서 조작 표시·가로 넘침을 확인.

## 공개 배포 확인

공개 배포 요청 시 변경 범위를 확인하고 `main`에 반영한 뒤 Pages 빌드 성공과 실제 공개 하위 경로·목록 링크를 확인합니다. 공개 파일과 로컬 파일의 내용도 대조합니다. 동봉 폰트의 cmap 검사는 다른 기기에서의 실제 렌더링 검증을 대신하지 않습니다.
